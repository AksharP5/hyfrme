# T3 Code: Thread Snooze

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. A Hyfrme thread opens the native action menu, chooses the three-hour Snooze preset, moves into the Snoozed shelf with T3's confirmation and inline banner, then reveals Wake thread.

Customize project, branch, thread titles and ages, conversation content, preset labels, toast and banner copy, and all five interaction beats through HyperFrames variables. Match project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
