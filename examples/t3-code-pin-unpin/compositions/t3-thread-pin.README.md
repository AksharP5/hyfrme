# T3 Code: Thread Pin

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. In the full Hyfrme workspace, a second thread is selected, its actual action menu opens, it is pinned and moves to the top, then its menu exposes Unpin thread.

Customize project, branch, thread titles and ages, conversation content, composer copy, menu actions, and the four interaction beats through HyperFrames variables. Match the project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
