# T3 Code: Thread Unpin

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. In the full Hyfrme workspace, a pinned thread's real action menu opens, Unpin thread restores it to active order, and its menu exposes Pin thread.

Customize project, branch, thread titles and ages, conversation content, composer copy, menu actions, and the three interaction beats through HyperFrames variables. Match the project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
