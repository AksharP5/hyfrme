# T3 Code: Open Local Project

This four-second block reproduces T3 Code v0.0.42 in dark or light mode at 1200 × 659 and 30 fps. In the real full Hyfrme workspace, New project opens the source chooser. Local folder searches an isolated filesystem path, selects hyfrme-motion-lab, and the native Add action creates the project and opens its new thread. No provider or repository account is used.

Customize the old and new project names, local path and search, chooser labels, sidebar, draft copy, appearance, and all four transition frames. The default chooser uses cropped official dark/light pixels. The browse crop comes from unchanged native frame 35 at the original bounds, removing only stale tooltip glyphs; the original crop remains preserved in source history. Its source hashes and exact comparison are packaged. An 857 × 34 strip preserves the pinned native tooltip placement history only with unchanged content and all four event frames; its source movie, ordered frame mapping, and image hashes are packaged. Changing content loads no native crops. Edited tooltip content and timing use the captured native markup and its source opacity/scale transition; changing timing loads no tooltip strips. Set matching variables on adjacent T3 Code blocks for a continuous workspace. Source: https://github.com/pingdotgg/t3code/tree/719a76ca1dbf5490f1aa33ffb9966301e02be9a9.
