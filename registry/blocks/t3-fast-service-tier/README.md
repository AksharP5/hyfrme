# T3 Code: Fast Service Tier

This four-second block reproduces the T3 Code v0.0.42 service-tier menu in dark or light at 1200 × 659 and 30 fps. The reference opens the native menu, hovers Fast, and selects it; the block mirrors the menu and lightning indicator. The model, reasoning, and service-tier options are seeded in an isolated local Hyfrme workspace with no provider configured; this capture exercises native controls and does not run AI inference. The default menu popup uses pixels cropped from the pinned native capture for exact small-text rendering; changing any visible content or service-tier choice switches to the editable native DOM snapshot.

Set the same theme, project, branch, thread, age, and prompt variables on adjacent T3 Code blocks for a continuous workspace. The default first frame is pixel-identical to Reasoning Level's native final frame in both themes. The menu opens at openFrame, highlights the selected service tier at hoverFrame, and commits it at selectFrame.
