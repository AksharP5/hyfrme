# T3 Code: Thread Wake

This four-second HyperFrames block reproduces official T3 Code v0.0.42 at 1200 × 659 and 30 fps in dark or light mode. The Snoozed shelf expands, the native menu opens from its Build a logo intro row at (128, 310), and Wake thread returns that row to Active. The snooze fields remain cleared after a native reload. The project and conversation are seeded; the local wake action and persistence execute. No AI provider or GitHub account runs.

Customize project, thread, conversation, shelf, menu labels, theme, and all four event frames. The default menu uses cropped official dark/light pixels; changed visible content uses source DOM.
