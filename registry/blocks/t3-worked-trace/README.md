# T3 Code: Worked Trace

This four-second HyperFrames block reproduces official T3 Code v0.0.42 at 1200 × 659 and 30 fps in dark or light mode. A completed turn's Worked for 2m row opens directly to one command. The command disclosure rotates without a separate body for this seeded activity. The trace closes and stays closed after a native reload. The Hyfrme conversation and command result are seeded; disclosure clicks and reload run in the official app. No AI provider or GitHub account runs.

Customize project, threads, conversation, command, appearance, and all four event frames. Use matching values with adjacent T3 Code blocks.
