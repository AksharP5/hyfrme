# T3 Code: Message Rewind

This four-second block reproduces the official T3 Code v0.0.42 “Edit from here” interaction at 1200 × 659 in desktop dark and light. Hovering the seeded Hyfrme prompt reveals the edit control, then opens the native confirmation with “Revert files too” and “Revert and keep changes.” The capture cancels the dialog and does not rewind the thread or restore files.

Pixel-verified mode reproduces the lossless native capture through one persistent canvas with synchronous frame draws from ten dark or eleven light deduplicated native PNG states. These PNGs are decoded from the unchanged pinned native FFV1 recording; every reconstructed frame preserves the native RGBA pixels. Editing the project, branch, thread labels, prompt, response, confirmation copy, or event timing automatically uses editable DOM. Unchanged content and timing retain the native recording in either theme; editable DOM mode can also be selected explicitly. Every native frame atlas round-trips at SSIM 1.0.
