# T3 Code: Agent Work

This four-second block reproduces the official T3 Code v0.0.42 workspace at 1200 × 659 in desktop dark and light. Its native capture follows a Hyfrme prompt from Thinking to a live npm command, expands the command details, then collapses them. The live command state is seeded in an isolated local workspace; no AI provider executes.

The default pixel-verified mode replays the lossless native capture through one persistent canvas with synchronous frame draws. Editing content or event timing automatically uses editable DOM. Unchanged content and timing retain the native recording in either theme; editable DOM mode can also be selected explicitly. The pinned default native capture strips round-trip every frame at SSIM 1.0. Source: https://github.com/pingdotgg/t3code/tree/719a76ca1dbf5490f1aa33ffb9966301e02be9a9.
