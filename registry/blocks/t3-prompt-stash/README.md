# T3 Code: Prompt Stash and Recall

This four-second HyperFrames block reproduces official T3 Code v0.0.42 at 1200 × 659 and 30 fps in dark or light mode. A Hyfrme prompt is stashed with Ctrl+S, appears in a badge drawer at (366, 407), survives a native reload, and returns through its Restore control. A second stash demonstrates that Ctrl+S on the empty composer directly restores a single entry. The Hyfrme conversation is seeded; stash, restore, and local persistence execute in the official app. No AI provider or GitHub account runs.

Customize the project, thread, conversation, prompt, stash labels, theme, and all six event frames. Use matching values with adjacent T3 Code blocks.
