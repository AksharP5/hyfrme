# T3 Code: Prompt Stash and Recall

This four-second block uses official T3 Code v0.0.42 at 1200 × 659 and 30 fps. A Hyfrme prompt is stashed with Ctrl+S, inspected in the drawer, restored after reload, and restored directly with Ctrl+S when there is one entry. The conversation is seeded; stash and persistence execute in the native reference app without an AI provider or GitHub account.

Unchanged dark defaults replay three pristine full-size native PNG states. Light defaults use source DOM. Editing any content or any of the six event frames automatically uses editable DOM. Editable DOM preserves the genuine 1200 ms pulse and native 200 ms badge color transition, including the original action settling time and reload lifecycle. Customized output is editable source, not a pixel-parity claim.
