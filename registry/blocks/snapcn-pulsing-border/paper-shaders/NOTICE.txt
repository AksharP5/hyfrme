https://github.com/paper-design/shaders

Apache-2.0 source commit: f9f2a8b2edeb78ec59256c4dc571f5eaf943d798

Hyfrme compiles and bundles these Apache-licensed sources into its HyperFrames component runtime. During compilation, shader-mount.ts is adapted to remove its wall-clock delta-time branch and requestAnimationFrame scheduler, hold playback speed at zero, and accept explicit setFrame updates while preserving the source shader u_time calculation. React wrappers provide namespaced font families. The frozen TypeScript source files remain unchanged.

The original project contains no separate NOTICE file at this commit.
