# T3 Code: Thread Pin

This four-second, 1200 × 659 block reproduces T3 Code v0.0.42 at 30 fps. Right-clicking the unpinned row opens its sidebar context menu beside the row. Pin moves the thread to the top through the native 150 ms row transition, and the menu then offers Unpin thread. The theme variable selects independently captured dark or light source states.

Customize theme, project, branch, thread titles and ages, conversation content, composer copy, menu actions, and the three interaction beats through HyperFrames variables. Match the project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/719a76ca1dbf5490f1aa33ffb9966301e02be9a9.
