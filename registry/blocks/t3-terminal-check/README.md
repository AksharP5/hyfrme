# T3 Code: Terminal Check

This four-second block captures the official T3 Code v0.0.42 source-file tab, add-surface menu, and live local terminal command at 1200 × 659 and 30 fps in dark and light themes. The real shell runs `git status --short` in an isolated Hyfrme demo repository; no AI provider or GitHub account is involved.

Project, source file, thread labels, shell prompt/branch/command/output, theme, and interaction frames are HyperFrames variables. The default terminal pixels come from the native Ghostty canvas, including cursor states and the floating toolbar; edited command/output values restore the genuine toolbar and use a customizable HTML terminal surface. The unchanged default source viewer uses a 283 × 256 native code-region image, and its add-surface menu shows a 92 × 28 native control-group image at frames 20–39. Any content or timing edit restores the editable source DOM and controls and loads neither image. Source: https://github.com/pingdotgg/t3code/tree/719a76ca1dbf5490f1aa33ffb9966301e02be9a9.
