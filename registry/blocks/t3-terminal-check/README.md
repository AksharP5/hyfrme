# T3 Code: Terminal Check

This four-second block captures the official T3 Code v0.0.42 source-file tab, add-surface menu, and live local terminal command at 1200 × 659 and 30 fps in dark and light themes. The real shell runs `git status --short` in an isolated Hyfrme demo repository; no AI provider or GitHub account is involved.

Project, source file, thread labels, shell prompt/branch/command/output, theme, and interaction frames are HyperFrames variables. The default terminal pixels come from the native Ghostty canvas, including cursor states; edited command/output values use a customizable HTML terminal surface. Source: https://github.com/pingdotgg/t3code/tree/719a76ca1dbf5490f1aa33ffb9966301e02be9a9. Installed files include T3 Code and Pierre attribution and license files.
