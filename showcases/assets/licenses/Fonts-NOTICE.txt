Hyfrme Remocn Collections showcase assets

Fonts are frozen from the exact URLs resolved by @remotion/google-fonts 4.0.481 for the current six upstream default compositions. Original binaries and OFL-1.1 licenses are included without modification. The URL, descriptor, SHA-256, and license source of every font are recorded in manifest.json.

Media files are unchanged copies of the current upstream public files. Existing showcase shader code and its PolyForm Shield notices are maintained separately; this snapshot introduces no new shader software.
