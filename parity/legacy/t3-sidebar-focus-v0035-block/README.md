# T3 Code: Sidebar Focus

This four-second block reproduces the T3 Code v0.0.35 sidebar collapse and restore at 1200 × 659 and 30 fps. It uses the pinned full workspace DOM and CSS, including the native 200 ms linear slide, around a Hyfrme source request.

Set the same project, branch, thread, age, and prompt variables on adjacent T3 Code blocks for a continuous workspace. collapseFrame, restoreFrame, transitionMs, and sidebarWidth control the framing.
