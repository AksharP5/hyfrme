# T3 Code: Reasoning Level

This four-second block reproduces the T3 Code v0.0.35 reasoning menu at 1200 × 659 and 30 fps. It opens the menu above the composer and selects High. The full T3 Code workspace remains visible throughout.

Set the same project, branch, thread, age, and prompt variables on adjacent T3 Code blocks for a continuous workspace. The picker opens at openFrame and commits the selection at selectFrame.
