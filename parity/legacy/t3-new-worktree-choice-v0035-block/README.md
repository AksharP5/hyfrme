# T3 Code: New Worktree Choice

This four-second block reproduces the T3 Code v0.0.35 Workspace selector at 1200 × 659 and 30 fps. It starts with the same project and prompt as t3-brief-to-prompt, opens the Workspace selector, and selects New worktree. The native footer changes from Current checkout to New worktree, with From origin/main as the base branch.

Set the same project, branch, thread, age, and prompt variables on adjacent T3 Code blocks for a continuous workspace. The selector opens at openFrame and commits the worktree choice at selectFrame.
