# T3 Code: Thread Actions

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. The selected Hyfrme thread opens its real action menu, reveals the Snooze submenu, then returns to the full workspace.

Customize the project, selected thread, conversation, sidebar, footer, menu copy, and opening, submenu, and closing frames through HyperFrames variables. Match project, branch, and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
