# T3 Code: Project Scope

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. The real project scope menu moves the sidebar from All projects to hyfrme-motion-lab and back to hyfrme. The chosen radio stays selected while the page is open; pinned v0.0.35 resets this scope to All projects on reload.

Customize both project names, the thread list, conversation, empty state, menu copy, and all five interaction beats through HyperFrames variables.
