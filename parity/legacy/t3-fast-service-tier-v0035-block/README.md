# T3 Code: Fast Service Tier

This four-second block reproduces the T3 Code v0.0.35 service-tier menu at 1200 × 659 and 30 fps. It opens the native reasoning menu, selects Fast, and shows the native Fast indicator beside the model. The full T3 Code workspace remains visible throughout.

Set the same project, branch, thread, age, model, reasoning, and prompt variables on adjacent T3 Code blocks for a continuous workspace. The menu opens at openFrame and commits Fast at selectFrame. You can customize the tier labels, detail, workspace copy, and timing. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
