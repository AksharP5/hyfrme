# T3 Code: Diff Review

This four-second block reproduces T3 Code v0.0.35 at 1200 × 659 and 30 fps. A real Hyfrme Logo Enter Git change opens in the native Working tree diff, then changes from stacked to split view. The Pierre diff viewer is restored from captured T3 shadow DOM and styles. At the pinned default content, the code area uses two cropped native canvases to preserve the exact diff font raster. Changing visible content switches the same area to editable Pierre DOM.

Project, conversation, diff text, counts, and interaction timing are editable. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
