# T3 Code: Worked Trace

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. Its real finished-turn disclosure opens to reveal a command activity and closes again in the full Hyfrme workspace.

Customize the thread, message, reply, command, sidebar, footer, and opening and closing frames through HyperFrames variables. Match project, branch, and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
