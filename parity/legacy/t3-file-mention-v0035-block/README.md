# T3 Code: File Mention

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. The real Hyfrme workspace composer opens its @ path drawer, searches local project files, highlights Logo Flicker, and inserts T3's native Lexical file chip. The bare @ state intentionally shows no matches until a query is entered.

Customize project and thread copy, typed prompt/query, all seven result labels and paths, the selected chip, and transition frames through HyperFrames variables. No AI response is simulated.
