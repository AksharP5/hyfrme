# T3 Code: Agent Work

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. A live Hyfrme agent shows Thinking, starts a command, reveals its command detail, then collapses the detail while work continues. Each state is captured from the pinned T3 Code app. It does not portray a finished answer.

Customize the project, thread, prompt, working labels, command, sidebar, footer, and phase frames through HyperFrames variables. Match project, branch, and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
