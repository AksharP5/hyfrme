# T3 Code: Thread Wake

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. A snoozed Hyfrme thread expands its shelf, opens the native action menu, and wakes back into Active.

Customize project, branch, thread titles and ages, conversation, sidebar, menu, banner, and the three interaction beats through HyperFrames variables. Match project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
