# T3 Code: Model Swap

This four-second block reproduces the T3 Code v0.0.35 model picker at 1200 × 659 and 30 fps. It starts with the same project and prompt as t3-brief-to-prompt, opens the picker, and selects GPT-6-Sol. The selected model also changes the native reasoning control to Medium.

Set the same project, branch, thread, age, and prompt variables on adjacent T3 Code blocks for a continuous workspace. The picker opens at openFrame and commits the selection at selectFrame.
