# T3 Code: Open Local Project

This four-second block reproduces T3 Code v0.0.35 at 1200 × 659 and 30 fps. In the real full Hyfrme workspace, New project opens the source chooser. Local folder searches an isolated filesystem path, selects hyfrme-motion-lab, and the native Add action creates the project and opens its new thread. No provider or repository account is used.

Customize the old and new project names, local path and search, chooser labels, sidebar, draft copy, and all four transition frames. Set matching variables on adjacent T3 Code blocks for a continuous workspace. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
