# T3 Code: Prompt Stash and Recall

This four-second block reproduces T3 Code v0.0.35 at 1200 × 659 and 30 fps. Its Hyfrme-only prompt is drafted in the full workspace, stashed with the native Ctrl+S shortcut, displayed in T3 Code's stash menu, and recalled with Enter. The four native interaction beats are held across 120 frames.

Project, thread, prompt, stash text, model, permission, workspace, and beat timing are editable. Set matching values on adjacent T3 Code blocks for a continuous workspace. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529. The installed files include the T3 Code MIT license.
