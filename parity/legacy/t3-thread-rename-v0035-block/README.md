# T3 Code: Thread Rename

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. The selected Hyfrme thread opens its real action menu, enters the native title editor, types a new title, and commits it in the sidebar and header.

Customize both titles, project, conversation, sidebar, footer, menu copy, and each rename beat through HyperFrames variables. Match project, branch, and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
