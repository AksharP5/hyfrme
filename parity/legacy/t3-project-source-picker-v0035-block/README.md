# T3 Code: Project Source Picker

This four-second block reproduces T3 Code v0.0.35 at 1200 × 659 and 30 fps. It starts in the full Hyfrme workspace, opens the real New project source chooser, and closes it with Escape. The chooser shows Local folder, Git URL, GitHub repository, and the native Setup Required states for Azure DevOps, Bitbucket, and GitLab in this fixture. No repository account data is embedded.

Set the same project, branch, thread, age, and composer variables on adjacent T3 Code blocks for a continuous workspace. The chooser opens at openFrame and closes at closeFrame.
