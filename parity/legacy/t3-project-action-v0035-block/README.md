# T3 Code: Project Action

This four-second block captures T3 Code v0.0.35 at 1200 × 659 and 30 fps. The real Add Action dialog receives a Hyfrme check name, command, and shortcut, then the saved action appears in the toolbar and its menu. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.

Project and thread copy, action name, command, shortcut, and all six interaction beats are editable. The installed files include T3 Code's MIT license and its bundled third-party icon notice.
