# T3 Code: Thread Archive

This four-second, 1200 × 659 block reproduces T3 Code v0.0.35 at 30 fps. The Hyfrme thread is archived through its actual action menu and disappears from the active sidebar. T3 navigates to a draft. Settings > Archive then shows the retained thread and its native Unarchive control; clicking it returns the settings page to an empty archive.

Customize project, branch, thread titles and ages, conversation, draft, Settings copy, menu actions, and the four interaction beats through HyperFrames variables. Match project and thread values with adjacent T3 Code blocks for continuity. Source: https://github.com/pingdotgg/t3code/tree/f925d639421844f02b3166d29281905dbba6d529.
