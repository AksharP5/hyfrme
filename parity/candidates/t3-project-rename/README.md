# T3 Code: Project Rename

This four-second, 1200 × 659 block reproduces the real project settings rename flow in T3 Code v0.0.35 at 30 fps. A Hyfrme project is opened from the sidebar project menu, renamed in its Project Name field, and shown again in the full workspace. The isolated native fixture confirms the new title in SQLite and after reload.

Customize both project names, checkout path, thread/conversation content, settings copy, and all five interaction beats through HyperFrames variables.
